\chapter{Introduction}
\label{chap:introduction}

\section{Contexte du Projet}

Dans le cadre de la formation AWS Academy, ce projet vise à mettre en œuvre une \textbf{infrastructure cloud de supervision centralisée} sur Amazon Web Services (AWS). L'objectif principal est de déployer une solution de monitoring complète capable de surveiller un parc informatique hybride composé de machines Linux et Windows.

La supervision des infrastructures informatiques est devenue un enjeu majeur pour les entreprises. Elle permet de :
\begin{itemize}
    \item Détecter les anomalies et les pannes en temps réel
    \item Anticiper les problèmes de performance
    \item Optimiser l'utilisation des ressources
    \item Garantir la disponibilité des services
\end{itemize}

\section{Objectifs du Projet}

Ce projet a pour objectifs :

\begin{enumerate}
    \item \textbf{Déployer une infrastructure AWS} : Création d'un VPC, configuration des sous-réseaux et des groupes de sécurité
    \item \textbf{Installer Zabbix avec Docker} : Mise en place d'un serveur Zabbix conteneurisé pour la centralisation du monitoring
    \item \textbf{Configurer la supervision hybride} : Installation et configuration des agents Zabbix sur des clients Linux et Windows
    \item \textbf{Valider le monitoring} : Démonstration de la collecte de métriques et de la génération d'alertes
\end{enumerate}

\subsection{Docker}

Docker est une plateforme de conteneurisation qui permet de :
\begin{itemize}
    \item Empaqueter les applications avec leurs dépendances
    \item Garantir la portabilité et la reproductibilité
    \item Simplifier le déploiement et la mise à jour
\end{itemize}

\subsection{Zabbix}

Zabbix est une solution de monitoring open source de niveau entreprise, capable de surveiller :
\begin{itemize}
    \item Les métriques système (CPU, RAM, disque, réseau)
    \item Les services et applications
    \item Les équipements réseau
    \item Les environnements cloud
\end{itemize}

\section{Architecture Cible}

L'architecture déployée comprend :

\begin{itemize}
    \item \textbf{1 VPC} avec un sous-réseau public (10.0.0.0/16)
    \item \textbf{3 instances EC2} :
    \begin{itemize}
        \item Serveur Zabbix (t3.large) - Ubuntu avec Docker
        \item Client Linux (t3.medium) - Ubuntu avec agent Zabbix
        \item Client Windows (t3.large) - Windows Server avec agent Zabbix
    \end{itemize}
    \item \textbf{Security Groups} configurés pour les ports nécessaires
\end{itemize}
